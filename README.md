# xia_Yue (瞎越)



### 2026-03-25 瞎越v1.5 (二开增强版)

#### v1.5 新增核心逻辑详细说明：

**1. 请求去重逻辑 (Deduplication Logic)**
* **逻辑去重模式 (默认)：** 计算公式为 `MD5(基础URL + 所有参数名 + HTTP方法)`。
  * 这种模式会自动忽略参数值的变化。例如 `GET /api?id=1` 和 `GET /api?id=2` 会被视为重复包，只检测一次。
  * 适合在大流量测试中快速覆盖接口。
* **全包MD5去重模式：** 直接计算原始请求包完整字节流的 MD5。
  * 勾选全包MD5去重复选框后，规则实时生效。
  * 请求包中任何一个字符的变化（包括 Header、Cookie、Body）都会触发重新检测。
  * 适合对接口进行精细化漏洞挖掘。
  

**2. CSV 导出逻辑 (Export Logic)**
* **智能过滤：** 点击导出按钮时，若有勾选行，则只导出选中行；若无勾选或全选，则导出所有测试结果。
* **漏洞自动标注：** 导出的 CSV 比 UI 界面多出一列 **“检测结论”**。如果低权限或未授权长度包含 `✔` (与原始包完全一致)，该列标记为 **“可能存在越权”**，方便在 Excel 中一键筛选。
* **Excel 兼容性：** 自动添加 `UTF-8 BOM` 头部，解决 Windows Excel 打开乱码问题；文件名带秒级时间戳，防止覆盖。
